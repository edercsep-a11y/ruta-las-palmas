# Cómo se actualiza esta herramienta

- Solo se edita `data.js`. No tocar `index.html` (diseño, logo y foto).
- Cada dato debe venir de una fuente oficial o de un medio serio que cite a la fuente oficial:
  ATU / MTC (gob.pe), Arzobispado de Lima, Comisión de la visita papal, Municipalidades de Lima, Surco, Barranco y Chorrillos, Línea 1, Metropolitano, Andina, TV Perú, Infobae, El Comercio, RPP.
- Si una noticia no es clara o se contradice con otra, NO se cambia el dato.
- Después de verificar, se actualizan `updated` y `short` con la hora de la verificación (hora de Lima).
- Cada cambio se registra abajo, con la fuente.
